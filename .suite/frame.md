# Frame

Drafted from the rebuild plan's intent. Waits for your confirmation (FRAME-G4, rebuild decision R1).

## Job

When a team starts or continues a software project, they want one way of working that takes the idea to a running, maintained system on CNCF tooling, open standards and open source practice, so that every project meets the same baseline without re-deciding how to work.

## Problem today

Each project starts from a blank page, picks its own tools and standards, and drifts. The 0.x skills were made one at a time and do not form one system (see the rebuild plan's diagnosis).

## Riskiest assumption

Teams will stay on a gated workflow instead of bypassing it when it feels heavy (OUT-3). Evidence: weak. Wave 1 and 2a ran end to end, but only with the maintainer.

## Cheapest next test

Run one real project of yours through frame to plan on the rebuilt skills (release R2). Pass if it reaches the plan gate without skipping a stage and you would choose to do it again.

## Decisions it rests on

D1 one standard workflow on CNCF, open standards and OSS practice; D2 software only; D3 adopt before build; D4 built from scratch, borrowing ideas.
