# Security policy

## Reporting a vulnerability

Report security problems privately through GitHub's private vulnerability reporting: open https://github.com/soilmass/dev-workflow-suite/security/advisories/new.

Do not open a public issue for a security problem.

## Security contact

The maintainer, @soilmass on GitHub, is the security contact. Use the private reporting link above.

## Response time

We acknowledge reports within 7 days and aim to publish a fix or advisory within 90 days.

## Scope

The skills in `plugins/` and the maintainer scripts in `scripts/`. Prompt-injection weaknesses in skill text count as security problems.
