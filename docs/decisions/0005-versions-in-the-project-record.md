# Versions in the project record

## Context and problem statement

After learn, a new version returns to plan, which the stage check could not follow. You said yes on 2026-11-18.

## Considered options

1. A version field in the header and on every gate row, checked by REC-13
2. Keep the 0.x arrangement

## Decision outcome

Chosen option: "A version field in the header and on every gate row, checked by REC-13".

### Consequences

- Good: projects can run many versions in one record
- Bad: gate rows carry one more column
